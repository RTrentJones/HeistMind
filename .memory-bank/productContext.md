# Product Context: HeistMind

## Problem Statement

### Target Users

#### Game Masters (Primary Users)
- **Experienced GMs**: Veterans running multiple FitD campaigns with custom rules and house modifications
- **System Adapters**: GMs who create variants of existing FitD games or adapt rules for their tables
- **Community Leaders**: GMs who run games for online communities and need streamlined player management

#### Players (Secondary Users)
- **FitD Enthusiasts**: Players familiar with Blades in the Dark and other FitD systems
- **New Players**: Individuals new to FitD games who need guided character creation
- **Multi-Game Players**: Players participating in multiple campaigns with different rulesets

### Core Problems Solved

#### For Game Masters
1. **Ruleset Fragmentation**: No centralized way to manage custom FitD variants and house rules
2. **Player Onboarding Complexity**: Difficulty explaining custom rules and helping players create valid characters
3. **Game Session Management**: Scattered tools for managing players, invitations, and game-specific content
4. **Content Validation**: No systematic way to ensure custom rules create balanced, playable characters
5. **Multi-Game Coordination**: Managing multiple campaigns with different rulesets becomes overwhelming

#### For Players
1. **Rule Confusion**: Difficulty understanding custom rulesets and their implications for character creation
2. **Character Validity**: Uncertainty about whether character builds are legal within specific game rules
3. **Progression Tracking**: Manual tracking of advancement across different rule systems
4. **Game Discovery**: No easy way to find and join games that match their interests
5. **Multi-Character Management**: Difficulty managing characters across multiple games with different rules

## User Experience Goals

### Game Master Experience Principles

#### Content Management Flow
1. **Upload Simplicity**: Drag-and-drop ruleset upload with intelligent validation
2. **Rule Visualization**: Clear representation of how custom rules affect character creation
3. **Validation Feedback**: Immediate feedback on ruleset completeness and potential issues
4. **Version Control**: Track changes to rulesets and their impact on existing games

#### Game Creation Workflow
1. **Template-Driven Setup**: Quick game creation using uploaded rulesets
2. **Player Invitation**: Multiple invitation methods (email, link sharing, invitation codes)
3. **Permission Management**: Granular control over player capabilities within games
4. **Game Monitoring**: Dashboard view of all active games and player activity

### Player Experience Principles

#### Game Discovery & Joining
1. **Intuitive Browsing**: Easy discovery of available games matching player interests
2. **Rule Preview**: Clear explanation of game-specific rules before joining
3. **Seamless Onboarding**: Guided process from invitation to character creation
4. **Flexible Participation**: Easy addition/removal of characters from games

#### Character Management
1. **Guided Creation**: Wizard-based character creation respecting game-specific rules
2. **Visual Feedback**: Clear indication of rule constraints and character validity
3. **Progression Tracking**: Automated XP calculation and advancement options
4. **Character Portability**: Understanding of which characters work in which games

## Market Context

### Current Landscape Challenges

#### Existing Solutions Limitations
- **Generic VTTs**: Virtual tabletops lack FitD-specific character creation support
- **Static Character Sheets**: PDF forms don't validate custom rules or guide creation
- **Homebrew Platforms**: General homebrew tools don't understand FitD mechanics
- **Discord/Forums**: Text-based rule sharing lacks interactive validation

#### Gap in Market
- **No FitD-Specialized Platform**: No tool designed specifically for Forged in the Dark systems
- **Limited Custom Rule Support**: Existing tools can't adapt to house rules and variants
- **Poor Player Onboarding**: No guided experience for learning custom rulesets
- **Fragmented Game Management**: GMs use multiple tools for different aspects of game management

### Competitive Advantages

#### FitD Specialization
- **System Expertise**: Deep understanding of FitD mechanics and common variations
- **Intelligent Validation**: Rules engine that understands character creation constraints
- **Familiar Terminology**: Interface using established FitD vocabulary and concepts
- **Community Focus**: Features designed around typical FitD gaming patterns

#### Technical Innovation
- **Dynamic Rule Engine**: Flexible system adapting to any FitD variant
- **Modern UX**: Wizard-based interfaces reducing cognitive load
- **Multi-Tenant Architecture**: Secure isolation of GM content and player data
- **Extensible Design**: Platform grows with community needs and new systems
